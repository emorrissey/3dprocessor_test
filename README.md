# Intel Core Ultra Series 3 Interactive Experience

A Three.js product experience that presents Intel Core Ultra Series 3 processors
as an explorable silicon anatomy. The page highlights hybrid CPU cores, Intel
Arc graphics, NPU 5 architecture, the CPU/GPU/NPU AI PC model, Evo mobility,
Thunderbolt and Wi-Fi platform features, and edge-ready AI use cases.

## Prerequisites

- Node.js `>=22.13.0`
- pnpm

## Quick Start

```bash
pnpm install
pnpm run dev
pnpm run build
```

## Useful Commands

- `pnpm run dev`: start local development
- `pnpm run build`: verify the vinext build output
- `pnpm run test`: build and verify the rendered experience
- `pnpm exec tsc --noEmit --incremental false`: run a strict type check
